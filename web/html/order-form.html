발주 등록 / 수정

입력 순서: 거래처 → 주문자·연락처·이메일 → 제품 → 수량·MOQ·단가 → 세금·배송 → 발주일·단계 → 합계 확인(§5.3). 발주번호·등록정보는 읽기전용.

발주 등록임시 요청ID: 8f3a… (중복등록 방지 §8.1)
번호 날짜 = 최초 등록 시점의 한국 날짜. 소급 발주일과 다를 수 있음(§8.1).
예: 010-1234-5678 (하이픈 선택).
빈 값은 미저장.
미지정 시 서버 현재시각. 초기값은 서버시각 RPC.
빈 값은 NULL 저장.
명칭 확정 필요(§3.2): Y/N + 설명 병기.
건너뛰기·역행·완료 후 수정은 사유 필수(§8.3).

확인 모달 예시 (삭제 — 번호·거래처·주문자·제품 표시 + 사유 필수)

유효성 §6.3~§6.6: 공백만 입력 불가, 주문자·휴대폰 형식·이메일 형식, 수량 정수·범위, MOQ, 금액 음수 불가. 미저장 이동 시 확인. client_request_id 재시도는 동일 번호 반환(§8.1).
