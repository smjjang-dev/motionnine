발주 등록-
번호 날짜 = 최초 등록 시점의 한국 날짜. 소급 발주일과 다를 수 있습니다.
예: 010-1234-5678 (하이픈 선택).
빈 값은 미저장.
미지정 시 서버 현재시각. 초기값은 서버시각 RPC.
빈 값은 NULL 저장.
Y = 상품금액에 포함되어 추가 청구가 없고, N = 배송비를 별도로 청구합니다.
단계를 거꾸로 되돌리거나 건너뛰어 변경할 때, 완료된 발주의 금액을 바꿀 때는 사유가 필요합니다.

금액 미리보기 (저장은 DB 확정값)

상품금액 (수량×단가)100,000
상품 공급가액90,909
상품 VAT9,091
추가 배송 청구액0
배송 공급가액 / VAT0 / 0
최종 청구액100,000

저장 시 금액은 서버에서 확정됩니다. 미리보기와 다르면 저장된 값이 맞습니다.
