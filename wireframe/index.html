W-02

가입 · 이메일 인증 · 비밀번호 재설정

탭을 눌러 4가지 상태를 확인. 가입 직후 role/status는 서버가 pending/admin으로 강제(§4.2).

관리자 가입 신청

가입 확인·승인 안내를 받는 주소. Google 계정과 동일 주소 권장(임의 병합 금지).

가입 → app_members(role=admin, status=pending) 자동 생성. 이메일 확인 전 승인 불가(§4.2-3).

인증 메일을 보냈습니다.
new-admin@example.com 받은편지함(스팸함 포함)에서 24시간 내 링크를 눌러주세요.

무료 SMTP 한도 도달 시: “잠시 후 다시 시도 + Google 로그인(연결된 경우) 안내” 표시(§4.3).

인증 링크가 만료되었거나 이미 사용되었습니다.
사유: 만료 / 이미 인증 완료 / 다른 브라우저에서 열기(PKCE verifier 없음)

비밀번호 재설정

성공·실패 메시지 통일 (“입력한 주소로 안내를 보냈습니다”). 속도 제한 적용(§4.3).

경로 제안: /auth/confirm /auth/reset /auth/callback (§9.2). 다른 브라우저 오픈 시 재시작 안내 또는 token-hash 흐름 사용(§11.2-7).
