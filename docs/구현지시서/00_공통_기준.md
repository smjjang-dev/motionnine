# 00 공통 기준 (전 화면·전 기능 적용)

## 1. 기술 스택 (기획 §1)

- `HTML5 + Vanilla JS (ES Modules) + CSS` — 프레임워크 없음.
- 스타일: 기존 분리 파일 재사용 — `web/css/common.css` (레이아웃·버튼) / `components.css` (부품) / `responsive.css` (§5.4).
- 스크립트: `web/js/common.js` (PC/모바일 토글) / `tabs.js` (W-02) / `order-form.js` (W-05 미리보기, §7.1 그대로).
- 데이터: Supabase Free (Auth + PostgreSQL, RLS + RPC). 상시 서버 없음.
- 배포: Cloudflare Pages Free에 `web/` 정적 배포. Functions/Workers 추가 금지(추가 시 §14 재검토).
- 다운로드: html2canvas + jsPDF (브라우저 생성, MIT 고지 유지).

## 2. 폴더 규칙 (현재 와이어프레임 → 실구현 매핑)

```text
motionnine/
  docs/구현지시서/*.md      ← 본 지시서
  web/html/*.html            ← 화면 (index/login/signup/pending/orders/order-form/order-detail/admin/trash)
  web/css/*.css              ← common / components / responsive
  web/js/*.js                ← common / tabs / order-form (+ 신규: config, supabase-client, auth, order-api, money, datetime, export, admin)
  web/img/*                  ← logo.svg, favicon.svg (+ 기존 logo.jpg 유지)
```

- 신규 JS는 `web/js/`에 추가하고, 각 HTML에서 `../js/xxx.js` 상대경로로 로드한다.
- HTML 간 이동은 상대 링크 (`orders.html`, `order-form.html` …) — 현재 와이어프레임 내비 그대로.
- 공통 상단바 `.topbar` + `.topnav a.active`를 매 페이지에 유지한다.

## 3. 보안 규칙 (§4.4, §6.7)

- 브라우저에 포함 가능: Supabase URL + publishable key(또는 anon key). 절대 금지: `service_role`, Secret, OAuth Secret, SMTP 비밀번호.
- 권한 판정은 JWT role이 아니라 **DB membership(`get_my_access()`)**으로 매 요청 확인. 중지 후 다음 요청부터 차단.
- 입력 출력: `textContent` 사용, 임의 HTML 삽입 금지. CSP 적용, 라이브러리 버전 고정·자체호스팅.
- redirect allowlist: 실 배포 URL만. `noindex` 유지 (접근통제 아님).
- 에러 매핑: DB 내부 오류 노출 금지 → 아래 6번 코드로 한글 매핑.

## 4. 한국시간 규칙 (§8.2)

- DB 저장: `timestamptz`, API: ISO 8601 with TZ.
- 표시·입력·필터·번호날짜: 전부 KST. 필터 종료일은 `종료일+1일 00:00 KST 미만`으로 조회.
- 폼 초기 발주일: `get_server_time()` RPC의 KST. 저장 미지정 시 DB 현재시각.
- `datetime-local` 값에 `+09:00` 명시 후 변환. 단말 TZ 암묵 변환 금지.

## 5. 금액 규칙 (§7.1 — JS 미리보기와 DB 동일식)

`Q=수량, P=단가, A=Q×P, R=0.10, F=배송비(VAT포함)`, 전부 원 단위 `round` (0.5 올림).

```text
VAT Y: 공급가=A, VAT=round(A*R)
VAT N: 청구액=A, 공급가=round(A/1.1), VAT=A-공급가
포함 Y: 추가배송=0/0/0 (F는 참고값, 더하지 않음)
포함 N: 추가배송=F, 공급가=round(F/1.1), VAT=F-공급가
합계: 공급가합=상품공급+배송공급, VAT합=상품VAT+배송VAT, 최종=공급가합+VAT합
```

- 검산표(수량10·단가10000·배송비3000): N+Y=100,000 / N+N=103,000 / Y+Y=110,000 / Y+N=113,000.
- 불변조건: `supply + vat = total` (DB CHECK, 화면도 검증).

## 6. 대표 에러코드 (§9.1) → 한글 문구

`ACCESS_DENIED`(권한 없음·로그인 필요) / `VALIDATION_ERROR` / `MOQ_NOT_MET` / `ADMIN_LIMIT_REACHED` /
`LAST_OWNER_REQUIRED` / `VERSION_CONFLICT`(다시 불러오기) / `ORDER_NOT_FOUND`(없는 건·권한 없음 공통 문구) /
`DAILY_SEQUENCE_EXHAUSTED`(오늘 접수 마감, 내일 재시도) / `REQUEST_ID_CONFLICT`(입력 변경 후 재시도).
