# 06 W-06 상세·이력 — 구현 지시서

## 1. 목적·범위

단건 조회 + 계산내역(DB 확정값) + 등록/수정 메타 + 변경이력 + PNG/PDF 진입.
와이어프레임: `web/html/order-detail.html` · 진입: `order-detail.html?id={uuid}` · JS 신규: `order-detail.js`, `export.js`.

## 2. UI 구성

1. `.bar`: `발주 상세 {order_no}` + 단계 pill + `목록으로(orders.html)` `수정(order-form.html?id=)` `삭제(모달)`.
2. 좌측 `.kv`:
   거래처 / 주문자 / 연락처·이메일 / 제품·코드 / 옵션 / 수량·MOQ·단가 / 세금·배송(부가세N·포함Y + 배송비 참고값) /
   발주일·번호날짜(`다를 수 있음` 표기) / 등록(시각+등록자) / 최종 수정(시각+수정자+v).
3. `.summary`: 계산 내역 — 상품 공급가 / 상품 VAT / 추가배송(공급+VAT) / 합계행(공급합/VAT합/최종). **DB 반환값 그대로**, 재계산 금지.
4. `변경 이력`: `.timeline` — 시각·행위자·내용(수량 8→10 등)·사유·v2→v3. 액션: create/update/stage_change/delete/restore.
5. 우측 `.summary`: `[PNG 다운로드]`(primary) `[PDF 다운로드]`(dark) + 힌트(파일명·A4 DOM·폰트대기·다중페이지·이미지PDF 한계·개인정보 표시금지) + `.okbox` 포함 항목.

## 3. 데이터 명세

- 조회: `orders` 단건 (RLS). `ORDER_NOT_FOUND`는 없는 건·권한 없음 공통 문구: `발주를 찾을 수 없습니다.`
- 이력: `order_audit_logs(order_id, created_at DESC)` — before/after 포함. 감사 로그 수정·삭제 불가.
- 다운로드 직전: 최신 단건 + `get_my_access()` 재조회. 미저장 폼 출력 금지 (`저장 후 출력하세요`).

## 4. 파일명·출력 규칙 (상세는 10번)

- `모션나인_발주명세서_{order_no}.pdf` / `.png` (다중페이지는 `…_01.png`).
- 로그인 이메일·UUID·권한 표시 금지 (주문자 이메일은 명세서에 포함). 출력시각 KST 하단 표기.

## 5. 수용 기준

- [ ] 없는 건·권한 없는 건 구분 불가 (공통 문구).
- [ ] 복원 후에도 동일 번호·금액·이력 유지 (W-08 연계).
- [ ] 완료 상태 금액 수정 시 추가 확인 + 사유 기록.

## 6. 체크리스트

- [ ] `?id=` 없음·형식 오류 → 목록으로 안내 + 에러 표시.
- [ ] `textContent` 렌더링 (XSS 방지), 긴 옵션·제품명 줄바꿈 처리.
- [ ] 삭제된 건 상세: 일반 admin은 `ORDER_NOT_FOUND`, owner는 삭제 표시 + 복원 링크(`trash.html`).
