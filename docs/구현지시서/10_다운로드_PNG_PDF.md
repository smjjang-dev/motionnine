# 10 다운로드 PNG·PDF — 구현 지시서

기획 §10 전면. 파일: `web/js/export.js` 신규 + `order-detail.html`·`orders.html` 버튼 연결.

## 1. 상세 발주 명세서 (W-06)

- 문서명: `모션나인 발주 명세서`. 포함: 번호·거래처·주문자·연락처·이메일·발주일·제품·코드·옵션·수량·MOQ·단가·세금배송 조건·공급가·VAT·최종·단계 + 최초 등록일/자·최종 수정일/자·출력시각(KST).
- 제외: 로그인 이메일·UUID·권한 (§10.1). 주문자 이메일은 포함.
- 파일명: `모션나인_발주명세서_{order_no}.pdf` / `.png` (다중페이지 PNG는 `{order_no}_01.png`…).

### 생성 순서 (§10.2 그대로)

1. 클릭 시 최신 단건 + 권한 재조회. 미저장 폼이면 `저장 후 출력하세요.`
2. 모바일 화면 캡처 금지 → 고정폭 A4 비율 전용 출력 DOM(`#print-root`, 794px 기준) 구성.
3. 로컬 한글 폰트·이미지 로드 대기 (`document.fonts.ready` + img onload).
4. 페이지 단위 html2canvas → PNG Blob.
5. jsPDF A4에 이미지 배치 (표 행·금액요약 중간 절단 금지 — `page-break-inside: avoid`).
6. 저장/미리보기 후 `URL.revokeObjectURL()`.

- 초기 PDF는 이미지 기반: 한글 안정, 본문 검색·선택 미지원 → HTML 상세를 원본으로 안내.
- 외부 이미지 CORS (`crossOrigin=anonymous` + 실패 시 제외), 초대형 단일 캔버스 금지, iOS Safari 저장 동작 실기 검증.

## 2. 목록 PDF (W-04)

- 확인 모달: `현재 조건 전체 N건 중 최대 200건 [현재 페이지 | 조건 전체]` — 현재 페이지와 전체 혼동 금지.
- `exportOrders()` 단일 스냅샷 조회 (페이지네이션 중간 변경 섞임 방지, RLS 적용).
- 구성: 번호·발주일·거래처·주문자·제품/코드·수량·합계·상태 + 상단 검색조건 + 하단 페이지·출력시각.
- 200건 초과: `기간·필터를 좁혀주세요.` 200건은 기기 성능 기준 초기값(고정 무료한도 아님, §14.4).

## 3. 수용 기준 (§12.1)
