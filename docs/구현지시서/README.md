## 작업 원칙 (요약, 상세는 00번)

1. 와이어프레임 ID를 그대로 쓴다: 화면 `W-01~W-08`, 필드 ID `f-qty/f-price/f-vat/f-ship/f-fee`, 요약 ID `s-a/s-ps/s-pv/s-f/s-sv/s-t`.
2. 금액·번호·권한·시각은 **DB가 정답**. JS 미리보기는 참고용이며 저장 응답값으로 다시 렌더링한다.
3. `service_role`/SMTP 비밀번호/OAuth Secret을 프런트·문서·Git에 넣지 않는다.
4. 모든 날짜·필터·번호 날짜는 **KST 기준**. `datetime-local`을 단말 TZ로 암묵 변환하지 않는다.
5. 각 지시서 하단 체크리스트를 모두 통과해야 다음 단계로 간다.
